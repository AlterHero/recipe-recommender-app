# 🍽️ Recipe Recommender App

Рекомендательное приложение, которое подбирает рецепты на основе введённых ингредиентов. Построено на Python + Streamlit + ML (RandomForest).

## 🚀 Запуск

1. Скачайте [13k-recipes.csv](https://raw.githubusercontent.com/josephrmartinez/recipe-dataset/main/13k-recipes.csv)
2. Поместите файл в папку `data/` внутри проекта.
3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Запустите приложение:

```bash
streamlit run recipe_recommender_streamlit_final.py
```

Откроется браузер по адресу: `http://localhost:8501`
